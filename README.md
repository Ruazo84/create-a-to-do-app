# ✅ To-Do App

A beautiful, modern, fully responsive To-Do web app built with vanilla HTML, CSS, and JavaScript. No build tools — runs directly in any browser.

## ✨ Features

- **Add tasks** with title, category, priority level, and optional due date
- **Complete tasks** with a satisfying checkbox animation
- **Edit tasks** inline with double-tap or the edit button
- **Delete tasks** with smooth slide-out animation
- **Filter by**: All / Active / Completed (tab bar)
- **Filter by category**: Personal, Work, Study, Shopping, Health, Other
- **Filter by priority**: High 🔴, Medium 🟡, Low 🟢
- **Sort**: Newest, Oldest, Priority, Due Date, A–Z
- **Full-text search** with real-time filtering
- **Progress bar** showing completion percentage
- **Stats** — Total, Active, Done counters
- **Dark / Light mode** (auto-detects system preference, persists your choice)
- **Export / Import** tasks as JSON
- **Persistent storage** via `localStorage` — survives page reloads
- **Due date highlighting** — overdue in red, today in yellow
- **Priority color-coded left border** on each task card
- **Mobile-first** — optimised for iOS Safari and Android Chrome

## 🚀 Usage

Just open `index.html` in any modern browser — no install, no server needed.

## 🌙 Dark Mode

Click the moon/sun icon in the top-right corner. The app also automatically respects your system's dark mode preference.
